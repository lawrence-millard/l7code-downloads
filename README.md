# L7CODE downloads

Desktop installers for [L7CODE](https://l7code.vercel.app). The app's source repository is private; this one exists only to host release binaries.

Each release is tagged with the app version and carries the macOS arm64 DMG and ZIP:

- `L7CODE-<version>-arm64.dmg`
- `L7CODE-<version>-arm64.zip`

The lander's download buttons link to these assets, so a new version means a new tag plus both files.
